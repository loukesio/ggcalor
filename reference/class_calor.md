# The ggcalor plot class

An S7 subclass of
[ggplot2::class_ggplot](https://ggplot2.tidyverse.org/reference/class_ggplot.html)
carrying the heatmap state in the `calor` property. Users never
construct it directly; see
[`ggcalor()`](https://loukesio.github.io/ggcalor/reference/ggcalor.md).

## Usage

``` r
class_calor(plot, calor = list())

class_calor_built(built, calor = list())
```
