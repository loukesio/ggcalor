# Colour bar guide used by ggcalor

A tall, narrow colour bar. Pass it as `guide` to any continuous fill
scale you add, to keep the look.

## Usage

``` r
calor_colourbar(height = 45, width = 3.5, ...)
```

## Arguments

- height, width:

  Bar size in millimetres.

- ...:

  Passed to
  [`ggplot2::guide_colourbar()`](https://ggplot2.tidyverse.org/reference/guide_colourbar.html).
