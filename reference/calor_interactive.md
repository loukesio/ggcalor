# Interactive cells with ggiraph

Turns the cells into 'ggiraph' interactive tiles with tooltips and
linked highlighting. Render with
[`calor_girafe()`](https://loukesio.github.io/ggcalor/reference/calor_girafe.md)
or
[`ggiraph::girafe()`](https://davidgohel.github.io/ggiraph/reference/girafe.html).

## Usage

``` r
calor_interactive(
  tooltip = NULL,
  data_id = c("cell", "row", "col"),
  tracks = TRUE
)
```

## Arguments

- tooltip:

  `NULL` for "row, column, value", or a function of `(row, col, value)`
  returning a character vector.

- data_id:

  What highlights together on hover: `"cell"`, `"row"` or `"col"`.

- tracks:

  Make categorical annotation tracks interactive too. With
  `data_id = "row"` or `"col"`, hovering a track cell highlights its row
  or column in the heatmap.

## Value

An object to add to a
[`ggcalor()`](https://loukesio.github.io/ggcalor/reference/ggcalor.md)
plot with `+`.

## Examples

``` r
if (requireNamespace("ggiraph", quietly = TRUE)) {
  m <- matrix(rnorm(50), 10, 5, dimnames = list(paste0("g", 1:10), paste0("s", 1:5)))
  p <- ggcalor(m) + calor_interactive(data_id = "row")
  calor_girafe(p)
}
```
