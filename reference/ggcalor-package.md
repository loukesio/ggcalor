# ggcalor: Heatmaps as a Grammar of Cells for 'ggplot2'

A 'ggplot2'-native grammar for heatmaps and other cell grids. Cells are
square by default and sized in absolute units, so the plot sizes itself
instead of the device. Rows and columns can be scaled, ordered,
clustered and decorated with dendrograms, and the result stays an
ordinary 'ggplot' object that accepts themes, scales and labels. 'calor'
is Spanish for heat.
